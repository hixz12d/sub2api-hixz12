# 上游 v0.2.11 融合

上游标签 `v0.2.11` 对应提交 `96f4c115c9749078f90cbf210a01d39baf3f53b6`，本分支版本为 `0.2.11-hixz12.1`。

## 当前行为

- 余额计费请求在 Redis 中预留估算费用，异步计费扣减余额缓存后释放；默认开启，订阅请求不预留。首次在途请求仍按旧准入规则放行，Redis 不可用或无法估价时默认放行，因此不是绝对禁止负余额。
- 用户默认最多持有 200 个未删除 API Key，每小时最多创建 60 次；删除 Key 不返还创建次数。
- Claude 原生额度重置支持确认操作，服务端选择可用额度，并以幂等记录和组织锁避免重复兑换。
- Codex 配置支持远程模型目录，超过客户端大小限制时使用本地下载文件；补齐当前订阅计划识别。
- GPT-6.1 Sol 使用上游内嵌的官方 Codex 描述：默认推理 low，Codex 默认上下文 272000、最大 872000，并含 ultra 档位。API 价格表的上下文能力与 Codex 描述分别保留。
- GPT-6.1 Sol 的兼容入口拒绝 none/minimal 推理设置，工具调用使用 Responses；带供应商前缀的别名仍识别为推理模型。
- Astra 支持 Ultrafast 的模型能力及六倍计费；本地基础价保持输入/缓存写入/缓存读取/输出每百万 token 10/12.5/2/50 美元，Fast 保持两倍，显式渠道价格仍优先。
- Claude Code 限制分组配置了降级分组时，OpenAI 兼容入口允许进入现有降级路由。

## 本地兼容处理

- 保留本地监控、支付、账号路由和 Codex 账号切换时重建上下文的实现。
- 合并服务装配代码，保留本地依赖，加入 Claude 额度重置所需的幂等与锁依赖。
- 复用本地模型价格定义，消除重复模型、重复价格变量和 JSON 同名项。
- 将既有回归用例对齐上游 Sol 能力和本地 Astra 定价；未新增测试框架。

## 发布边界

- 相对当前本地 main，无数据库迁移、依赖或运行时 Dockerfile 变更；部署目录仅配置示例新增选项。
- 原工作区未提交的 9 个文件独立保留，不纳入此版本。
- 按运维仓库 Runbook 本机编译、校验哈希、上传预编译二进制；服务器只打包镜像并按主备顺序滚动更新。
- 前端构建包含 i18n、类型检查和打包；相关 6 个前端测试文件共 168 项通过。后端执行基础编译及余额预留、限额、额度重置、模型、计费、兼容路由和会话相关既有回归。
